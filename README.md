# industrial-steel-defect-detection
Industrial Steel Surface Defect Detection using Deep Learning and Streamlit
## Industrial Steel Surface Defect Detection

This project uses Deep Learning and Convolutional Neural Networks (CNN) to automatically detect and classify surface defects in industrial steel images. It identifies six types of defects: crazing, inclusion, patches, pitted surface, rolled-in scale, and scratches.

The project uses a trained ResNet50 model to classify uploaded steel images and a Streamlit web application to provide user-friendly predictions. It aims to improve quality inspection, reduce manual effort, and support faster defect identification in industrial manufacturing.
